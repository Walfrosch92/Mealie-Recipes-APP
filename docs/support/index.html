Questions, problems or ideas? Here is how to get help with Mealie Recipes – a third-party app for your own Mealie server.

✉

Contact support

Write an e-mail to walfrosch92@gmail.com. Replies usually come within a few days, in English or German.

The fastest way is right from the app: Settings → Logs → Contact support. The app can attach a log file that helps to find the cause.

Please mention your device, the app version (shown in Settings) and your Mealie server version.

1

Bug reports & feature requests

You can also open an issue on GitHub – there you can see whether someone already reported the same problem:
github.com/Walfrosch92/Mealie-Recipes-APP/issues

2

The app can't connect to my server

  • Open your server address in the phone's browser. If it doesn't load there either, the problem is the network or the server, not the app.
  • Enter the full address including http:// or https:// and, if needed, the port (e.g. http://192.168.1.20:9000).
  • iPhone / iPad: if your server is in your home network, allow Local Network access: Settings → Privacy & Security → Local Network → Mealie Recipes.
  • Check that your API token is still valid. You can create a new one in the Mealie web app under your profile → API Tokens, or sign in with user name and password instead.
3

What do I need?

Mealie Recipes is not an official Mealie app and has no server of its own. You need a running Mealie server (self-hosted or provided by someone you know). All recipes, meal plans and shopping lists stay on that server.

Privacy

The app collects no personal data and contains no tracking or ads. Details: Privacy Policy.
